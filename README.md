closxom
=======

When I wanted to start a blog, I looked around for the
simplest blog software I could find, and found Blosxom.  I said “OK,
if I'm still blogging in six months I can find something better.”

It's twenty years later and I'm still using Blosxom, not
out-of-the-box Blosxom but a horrible Frankenstein's monster made of
a highly-modified and inadvisably patched Blosxom with a couple dozen
hacked and rehacked custom plugins.  It's terrible.

This will be the replacement.
